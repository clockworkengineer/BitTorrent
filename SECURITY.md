# Security Policy

## Supported Versions

We take security seriously. We provide security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** report it using a public GitHub issue.

Instead, please send an email with the following details to the project maintainers:
- **Title**: Vulnerability report with a brief description
- **Affected Components**: e.g., `bittorrent-rs` library, `bt_daemon`, `bt_webui`, `torrent_client`
- **Severity**: Low / Medium / High / Critical
- **Description**: Detailed explanation of the vulnerability and potential attack vectors
- **Reproduction Steps**: Step-by-step instructions or Proof of Concept (PoC) code
- **Suggested Remediation**: If you have identified a fix or mitigation

### Response Process

1. **Acknowledgment**: Within 48 hours of your report, a maintainer will acknowledge receipt.
2. **Investigation**: We will investigate and reproduce the issue, keeping you informed of progress.
3. **Patch & Release**: Once resolved, we will prepare a patch and coordinate a public release notes advisory.
4. **Credit**: We will credit your discovery in our security advisories and changelog unless you prefer to remain anonymous.
